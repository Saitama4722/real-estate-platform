Кнопка; primary — одно главное действие на экран, красного варианта для обычных действий не существует.

```jsx
<Button variant="primary" size="lg" icon="search">Найти</Button>
<Button variant="outline" icon="map">На карте</Button>
```

Варианты: primary, secondary (заливка blue-50), outline, ghost, danger (только деструктив, тёмно-красный), inverse (на синем фоне). Размеры sm/md/lg = 32/40/48px.
