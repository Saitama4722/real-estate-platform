# UI kit: сайт Centreal

Главная страница, собранная из компонентов системы.

- `index.html` — десктоп 1440: шапка, хиро с панелью поиска (pull-up), категории, новые объекты, карта с маркерами, band «Продать недвижимость», статьи, SEO-блок + «Остались вопросы?», подвал.
- `mobile.html` — 390: бургер-меню (работает), стековая панель поиска, категории 2×2, карточки в колонку.

Интерактив: переключатели Продажа/Аренда и Карта/Список, тогглы избранного/сравнения, бургер. Фото во 2–3 карточках — `<image-slot>`: перетащите реальные фото объектов.
