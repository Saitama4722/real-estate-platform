# Motion spec — Centreal

Движение здесь — обратная связь, а не украшение. Пользователь просматривает десятки карточек подряд: анимация не должна задерживать ни одно действие. Только ease-out, никаких bounce и overshoot, ничего дольше 360 мс.

## Токены (`tokens/motion.css`)

| Токен | Значение | Где |
|---|---|---|
| `--dur-instant` | 100ms | press/active состояния |
| `--dur-fast` | 150ms | hover иконок, ссылок, чипов |
| `--dur-base` | 200ms | hover кнопок, фокус полей, тени |
| `--dur-slow` | 250ms | подъём карточки, компактная шапка, смена вида |
| `--dur-reveal` | 360ms | появление секций при скролле (потолок) |
| `--dur-gallery` | 300ms | смена кадра галереи |
| `--ease-out` | `cubic-bezier(0.2, 0, 0, 1)` | по умолчанию |
| `--ease-out-soft` | `cubic-bezier(0.16, 1, 0.3, 1)` | появление, крупные перемещения |
| `--ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | только уход/скрытие |
| `--stagger-step` | 60ms | шаг стаггера в сетках, максимум 4 шага (240 мс) |

### Скролл и загрузка

| Элемент | Триггер | Меняется | Длит. | Кривая |
|---|---|---|---|---|
| Секция главной | пересечение вьюпорта на 12% | `opacity 0 → 1`, `translateY(16px) → 0` | 360ms | ease-out-soft |
| Карточки в сетке | то же, стаггер | задержка `60ms × индекс`, максимум 4 шага | 360ms | ease-out-soft |
| Шапка | `scrollY > 24px` | высота 64 → 52px, тень md, фон 92% + blur | 250ms | ease-out |
| Скелетон карточки/карты | ожидание данных | `ctr-shimmer`, фон-градиент, 1.4s linear infinite | — | linear |
| Галерея объекта | смена кадра | `opacity` кросс-фейд | 300ms | ease-out |
| Стрелки галереи | hover сцены | `opacity 0 → 1` | 200ms | ease-out |

### Хиро: иконное поле

| Слой | Размер | Прозрачность | Дрейф | Параллакс |
|---|---|---|---|---|
| back | 130–170px, blur 0.6px | 5% белого | 38s alternate, ±20px | 0.10 |
| mid | 70–85px | 8% белого | 30–34s alternate, ±18px | 0.18 |
| front | 30–40px | 12% белого | 24–27s alternate, ±16px | 0.28 |

Словарь иконок: building-2, house, land-plot, store, building, key-round, map-pin, door-open, ruler, trees — тот же Lucide, stroke 1.5 (тоньше интерфейсного, чтобы читалось как текстура).
Кривая дрейфа — `cubic-bezier(0.45,0,0.55,1)`, `animation-direction: alternate`, у каждой иконки своя отрицательная задержка: цикл не читается как общий такт. Ни вращения, ни пульсации, ни масштабирования.
Зона текста защищена маской слоя (`mask-composite: intersect`): радиальный вырез вокруг заголовка слева и линейное затухание к нижнему краю, где ложится белая карточка поиска. Карточка остаётся самым контрастным элементом экрана.
Десктоп — 16 иконок, мобильная — 7.
При `prefers-reduced-motion` дрейф и параллакс замирают, композиция остаётся статичной.

Появление секции срабатывает **один раз** (наблюдатель отключается) — при обратном скролле ничего не повторяется.

## prefers-reduced-motion

`tokens/motion.css` содержит блок `@media (prefers-reduced-motion: reduce)`, который:
- сводит все длительности к 1 мс и обнуляет стаггер;
- отключает перемещения: подъём карточки, scale фото, scale иконок и маркеров;
- показывает секции сразу (`.ctr-reveal` без анимации);
- останавливает shimmer скелетонов (остаётся ровная плашка).

Смысловые изменения — цвет, тень, обводка фокуса, заливка сердца — **сохраняются**: они несут состояние, а не декорацию.

## Правила реализации

1. Анимировать только `opacity` и `transform` (+ `box-shadow`, `background-color`, `border-color`). Никогда — `width`, `height`, `top`.
2. Никаких `ease-in-out` на входе, никаких пружин и `cubic-bezier` с overshoot.
3. Ни одно движение не блокирует клик: переходы состояний не имеют задержки.
4. Стаггер только для сеток первого экрана; в бесконечном каталоге карточки появляются без задержек.
5. Скелетон показывается, если ответ дольше 200 мс; иначе — сразу контент, без мигания.
