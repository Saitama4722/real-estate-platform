# Centreal Design System

Визуальная система для Centreal — регионального агентства недвижимости (Краснодар и Геленджик, продажа и аренда: квартиры, дома, участки, коммерция). Функциональный, product-first поиск в духе Zillow, адаптированный под локальное русскоязычное агентство: доверие и утилитарность, не люкс.

**Источник:** скриншот текущего сайта `uploads/01-homepage-desktop.png` (главная, десктоп). Логотип не предоставлен — везде словесный знак «Centreal» набором (Golos Text 700 + красная точка-плашка); настоящий знак заменит его позже.

## CONTENT FUNDAMENTALS

- Язык — только русский. Обращение на «вы» (строчное): «Оставьте заявку», «Напишите нам».
- Тон — практичный и доверительный, без люксовой лексики и восклицаний. Обещания конкретные: «Ваш телефон видят только сотрудники агентства».
- Заголовки — фразы без точки: «Новые объекты», «Остались вопросы?».
- Цены: `5 000 000 ₽` — пробелы-разряды, символ ₽ через пробел, всегда 700, `font-variant-numeric: tabular-nums`.
- Спеки объекта одной строкой: `1-комн. квартира · 45 м² · 8/8 эт.`
- Эмодзи не используются. Иконки — только Lucide.

## VISUAL FOUNDATIONS

- **Палитра — синий + красный + белый.** Один уверенный синий `--blue-600 #1A5FE0` (кнопки, ссылки, активные состояния, маркеры карты); hover `#124BC0`, active `#0E3C9B`. Тёмно-синий `--blue-950 #0F1E38` — хиро и подвал. Красный `--red-500 #DE2B37` — только внимание: «Цена снижена», активное сердце, горячие объекты; НИКОГДА не кнопки. Отдельный глухой красный `--carmine-600 #A1272F` — только ошибки/деструктив, чтобы не путался с акцентом.
- **Фоны** — тёплые: страница `#F6F5F1`, поверхности белые. Тёмных полос максимум две-три на страницу (хиро + синий band + подвал).
- **Контраст** — проверен AA: белый на blue-600 ≈ 5.6:1, белый на red-500 ≈ 4.7:1, red-500 на белом ≈ 4.7:1, carmine на белом ≈ 7:1, muted-текст `#6A7180` ≈ 5:1.
- **Шрифт** — Golos Text (400/500/600/700), полная кириллица, единственная семья. Шкала: display 44/52·700, h1 36/44·700, h2 28/36·700, h3 20/28·600, body 16/24, small 14/20, caption 12/16·500; цены 20/26 и 24/30·700.
- **Сетка** — 4px; контейнер 1200px; радиусы 4/8/12/16/999; тени 4 уровня (`--shadow-xs…lg`) + фокус-кольцо `--focus-ring` (синее, 3px, 25%).
- **Ховеры**: карточки — `shadow-md` + `translateY(-2px)` + фото scale 1.04 (400ms); кнопки — сдвиг тона на шаг темнее/насыщеннее; ссылки — к `--color-primary-hover`. Транзишены 140/220ms `cubic-bezier(0.2,0,0,1)`.
- **Карточка объекта** — иерархия строго: цена (крупнее всего) → спеки одной строкой с иконками 16px → адрес 13px muted с пином. Фото 4:3.
- **Карта — первоклассный элемент**: скругление lg, собственные белые контролы поверх, ценники-маркеры (`.ctr-marker`: синие; красные `--hot` для горячих; белые `--visited` для просмотренных).
- **Хиро** — одна задача: панель поиска. Углублённый навигационный градиент (#16305C → #0F1E38 → #0A1428) с двумя радиальными подсветками, поверх — дрейфующее поле иконок недвижимости на 5–12% белого; панель `shadow-lg` перекрывает границу секции (pull-up) и остаётся самым контрастным элементом.

## MOTION

Полная спецификация — `guidelines/motion.md` (таблица: элемент → триггер → свойство → длительность → кривая). Коротко:

- Токены в `tokens/motion.css`: 100 / 150 / 200 / 250 / 360 мс, только ease-out (`cubic-bezier(0.2,0,0,1)`; для появления `cubic-bezier(0.16,1,0.3,1)`). Bounce и overshoot запрещены.
- Наведение: карточка — тень sm→md + подъём 3px + фото ×1.04 (250 мс); кнопки, ссылки, чипы, маркеры — 150 мс. Нажатие — 100 мс.
- Микровзаимодействия: сердце и сравнение — смена цвета + `ctr-pop` (1 → 1.28 → 1); переключатели — переезд белой пилюли; фокус поля — обводка + кольцо 200 мс.
- Скролл: секции появляются через `.ctr-reveal` (opacity + 16px, 360 мс, один раз), сетки со стаггером 60 мс × индекс, максимум 4 шага. Шапка `.is-compact` после 24px: 64 → 52px, тень, полупрозрачный фон с blur.
- Загрузка: `.ctr-skeleton` (shimmer 1.4s linear) в геометрии карточки и карты; показывать, если ответ дольше 200 мс.
- Галерея объекта: кросс-фейд 300 мс, стрелки проявляются по hover.
- `.ctr-hero` — иконное поле: три слоя глубины (5/8/12% белого, крупные глуше и с blur), дрейф 24–38 с alternate, параллакс 0.10/0.18/0.28, маска освобождает зону заголовка и карточки поиска. Десктоп 16 иконок, мобильная 7.
- `prefers-reduced-motion: reduce` обнуляет длительности и все перемещения; цвет, тень и фокус сохраняются.

Хелперы: `components/feedback/reveal.js` — `initReveal()`, `initStickyHeader()`, `popIcon()`.

## ICONOGRAPHY

- Набор — **Lucide** (outline, stroke 2px, 24px-сетка), CDN: `https://unpkg.com/lucide@0.462.0/dist/umd/lucide.min.js`. В React — компонент `Icon` (грузит CDN сам), в статике — `<i data-lucide="…">` + `lucide.createIcons()`.
- Размеры: **16** — в тексте, спеках карточек; **20** — кнопки, навигация (по умолчанию); **24** — крупные действия; **28** — категории (в плашке 48px `--blue-50`).
- Словарь: search, sliders-horizontal (фильтры), map / list (переключатель), heart (избранное; актив — красная заливка), scale (сравнение; актив — синий), share-2, phone, chevron-*, menu, x, user (кабинет), circle-alert (ошибки). Категории: building-2 (Квартиры), house (Дома), land-plot (Участки), store (Коммерция). Спеки: bed-double (комнаты), ruler (м²), building (этаж), map-pin (адрес). Удобства на странице объекта: wifi, car (парковка), trees, arrow-up-down (лифт), shield-check (охрана), washing-machine.
- Своих SVG не рисуем; эмодзи и юникод-иконки не используются.

## Load-bearing решения (менять — дорого)

1. **Primary blue `#1A5FE0`** — прошит в кнопки, ссылки, маркеры, фокус-кольцо, активные состояния. Смена оттенка каскадирует на всё.
2. **Красный = внимание, глухой карминовый = ошибки.** Если позже захочется красных кнопок или красного в навигации — правило рушится по всем 32 страницам.
3. **Golos Text** — метрика шкалы (высоты кнопок 32/40/48, поля 40px) подогнана под него; замена шрифта потребует перепроверки всех контролов.
4. **Иерархия карточки объекта** (цена → спеки → адрес) и формат спеков одной строкой — это «единица сканирования» каталога; от неё зависят списки, сравнение, избранное, карта.
5. **Lucide как единственный иконочный словарь** и размерная сетка 16/20/24/28.
6. **Тёплый фон `#F6F5F1` + белые карточки без рамок (тени вместо бордеров)** — вся глубина строится на тенях; переход на бордеры — другая система.
7. **Бюджет движения: потолок 250 мс на состояние и 360 мс на появление, только ease-out.** Правило зашито в токены и во все переходы; поднять потолок — значит переразметить весь каталог.

## Индекс

- `styles.css` — входная точка (импортирует всё из `tokens/`).
- `tokens/` — colors, typography, spacing, effects, fonts, base.
- `components/components.css` — стили всех компонентов (классы `ctr-*`), источник правды; тот же CSS зашит в `components/core/Theme.jsx`.
- `components/core/` — Icon, Button, IconButton, Badge, Theme.
- `components/forms/` — Input, Select, Checkbox, Radio.
- `components/navigation/` — Header (desktop + mobile), Footer.
- `components/listing/` — PropertyCard, SearchBar, EmptyState, Gallery.
- `components/core/Chip` — чипы фильтров; `components/feedback/` — Skeleton, reveal.js.
- `guidelines/` — карточки-спецификации (цвета, типографика, отступы, тени, знак, движение) и `motion.md`.
- `ui_kits/website/` — главная: `index.html` (1440), `mobile.html` (390); варианты хиро — `hero-variants.html` (сравнение A/B), `hero-a*.html`, `hero-b*.html`.
- Варианты хиро: базовый (текстура 5–12%), `.ctr-hero--bold` (A, 16–30%, крупные силуэты), `.ctr-hero--photo` (B, фото + скрим).
- `assets/photos/` — реальное фото объекта (кроп со скриншота) и карта 2GIS.

## Известные допущения

- Golos Text подключён с Google Fonts (`tokens/fonts.css`); для самостоятельного хостинга заменить на локальные @font-face.
- Карта — статичный кроп 2GIS со скриншота, только как референс стиля; в продукте — живая карта с маркерами `.ctr-marker`.
- В «Новых объектах» реален только 1 объект (5 000 000 ₽, п. Северный); вторая и третья карточки — демонстрационные данные, фото — слоты для перетаскивания.
